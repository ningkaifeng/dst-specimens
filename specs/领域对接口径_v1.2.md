**标本库 · 领域对接口径 v1.2**

**〇、核心原则（宁老师 2026-11-07 定）**

· 三种动能（生成 / 维持 / 导向）与三种操作（源头改造 / 底线守护 / 共识凝聚）是"逻辑位置"，不是"技术 / 制度 / 思想"这些承载物。

· 承载物和落点都由"分析边界"决定——特定边界决定特定承载物、特定落点；边界一移，承载物与落点全量重排。这是治水学的核心。

· 对外对接 / 穿外衣，必须对接"逻辑位置"（能力），不能对接"承载物"（技术 / 制度 / 思想）。

· 结构层（语法层）只有一个"边界"问题，没有"存续单位"——"存续单位"是实体概念、属于存在域；实体、具体单位只出现在承载物层（具体领域的颗粒度）或工具层 / 执行层（具体操作时的单位）。标本结构层只写边界（边界画在哪、边界内能否识别出动力-规则关系），不写存续单位。

**一、三种动能（原生动力 · 逻辑位置）**

· 生成 = 能改变（系统产生改变的能力来源）

· 维持 = 能持续（系统维持持续输出的能力来源）

· 导向 = 能定向（系统定向的能力来源）

三者不可互替。技术 / 制度 / 思想只是它们在文明尺度最常见的经验承载物（隐喻名，非定义）：生成不依赖"技术"（细胞靠基因突变）、维持不依赖"制度"（习惯 / 惯例）、导向不依赖"思想"（利益格局 / 舆论）。

**二、三种操作（原生操作 · 逻辑位置）**

· 源头改造（疏浚）= 规则引导动力去改造压力源

· 底线守护（方舟）= 规则引导动力去守护系统边界（该结构失效则主要存续功能中断）

· 共识凝聚（祭祀）= 规则引导动力去凝聚主体间关系

承载物由分析边界决定，边界一移全量重排。

**三、防降格铁律**

《结构显影的判据》5.3："填出"技术、制度、文化三个并列板块"即为误翻译，因缺动力与规则相互拉扯，推倒重填。"

**四、"全球 AI 治理"这个边界下的承载物与落点（示例，非定义）**

下表仅对"全球 AI 治理（2024–2026）"这一特定边界成立；换一个边界（金融、气候、公共卫生），整张表重排。

【三种动能的承载物】

| 逻辑位置（原生动力） | 含义                | 本边界下此刻的承载物（非定义）       |
|----------------------|---------------------|--------------------------------------|
| 能改变（生成）       | 产生新能力 / 新状态 | 模型能力迭代、研发竞赛、开源创新     |
| 能持续（维持）       | 保持结构、持续输出  | 立法、备案、行业标准、惯例           |
| 能定向（导向）       | 定向、选方向        | 安全对齐叙事、价值共识、地缘竞争格局 |

【三种操作的落点】

| 逻辑位置（原生操作） | 作用对象   | 本边界下此刻的落点（非定义）       |
|----------------------|------------|------------------------------------|
| 源头改造（疏浚）     | 压力源     | 改造"模型失速 / 有害输出"本身      |
| 底线守护（方舟）     | 系统边界   | 守住"不可接受的模型 / 用途"红线    |
| 共识凝聚（祭祀）     | 主体间关系 | 把国家 / 企业 / 公众拉到同一张桌子 |

**五、节奏失配的正确表述（对接能力，不对接事物）**

错误（降格）："技术载体快、制度载体慢"。

正确（对接逻辑位置）："生成"的力量（模型能力月级迭代）与"维持"的力量（立法备案年级跟进）之间，时间常数差一个数量级——失配的不是"技术 vs 制度"，而是"改变的速度 vs 持续的跟速"。

**六、标本正文的外衣规则**

· 标本正文不给外行人裸奔治水学名词（三种动能 / 三元操作 / 疏浚 / 方舟 / 祭祀 / 体 / 分层异步），一律用领域语言 / 复杂系统语言 / 公共语言。

· 治水学逻辑位置 ↔ 领域语言的对应关系，放本《对接口径》与《写作纪律》，不在标本正文重复。

· 外衣三件套：主外衣＝复杂系统语言（节奏失配、2×2、锁定态、杠杆点）；落点用领域语言（模型发布、EU AI Act、备案制、对齐）；公共语言兜底。
